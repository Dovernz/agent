# Project Template (Boilerplate)

Thư mục này là mẫu chuẩn để nhân bản khi bạn bắt đầu một dự án mới.

## Cách tạo nhóm Agent cho Dự án Mới
1. Copy thư mục `_template` thành `projects/<ten-du-an-moi>`.
2. Mở file `knowledge/tech-stack.md` để điền công nghệ của dự án mới.
3. Thay thế tiền tố `[PROJECT_NAME]` trong tên và mô tả các file `SKILL.md`.
4. Đăng ký đường dẫn skills vào file `skills.json` ở thư mục gốc.
