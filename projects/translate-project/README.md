# GeminiTrans (Translate Project)

Dự án dịch thuật đa phương tiện siêu tốc và phụ đề video/phim realtime ứng dụng ma trận model Google AI Studio kết hợp Smart Key Pool 7 Cloud Projects.

## Thông Tin Cơ Bản
- **Workspace mã nguồn:** `d:\Thành\Translate`
- **Môi trường thực thi:** Docker Container (`geminitrans_app`, port `8090:8000`)
- **Git Repo:** `https://github.com/Dovernz/translate-project.git`
- **Tech Stack:** FastAPI, Python 3.12, Uvicorn, Docker, yt-dlp, WebSockets/SSE, Tailwind CSS, Google GenAI
- **Shard ID tương ứng:** `translate`
